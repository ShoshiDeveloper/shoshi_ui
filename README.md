ShoshiUI — a modern, lightweight, and easy-to-use UI kit for Flutter, designed to speed up building beautiful interfaces in your projects. Perfect for personal projects as well as team development.

## 🔹 Overview
ShoshiUI provides a collection of customizable widgets that help accelerate development and maintain a consistent, polished UI.

## 🚀 Features

- Clean and modern design, production-ready.
- Easily customizable components with full theme support.
- Quick integration into existing projects.
- Regular updates with new widgets and enhancements.

## 🔮 Upcoming Widgets

- Button
- Input
- BottomSheet
- Selector
- Alert
- Switch
- Checkbox
- SectionsList
- Steps

## 📦 Installation

```yaml
dependencies:
  my_flutter_ui_kit: ^0.1.0
```
